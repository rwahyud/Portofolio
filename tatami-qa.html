QA Automation — Tatami Control

Peran QA Automation Engineer
Tanggal 2026

Membangun framework otomasi pengujian untuk Tatami Control — sistem manajemen pertandingan karate berbasis web. Mengotomatiskan alur scoring juri, jadwal pertandingan, dan manajemen hasil untuk memastikan turnamen berjalan tanpa hambatan.

Live Demo →
01

Kenapa QA Automation?

Tatami Control adalah sistem yang dipakai langsung saat pertandingan karate berlangsung — di mana akurasi dan real-time data jadi segalanya. Kesalahan kecil di sistem bisa berdampak besar: nilai juri yang salah, urutan pertandingan yang kacau, atau hasil turnamen yang tidak sinkron.

Gue membangun otomasi pengujian untuk memastikan semua alur kritis bekerja dengan benar sebelum dan selama event. Dengan test yang bisa jalan otomatis setiap ada perubahan kode, risiko bug saat pertandingan berlangsung bisa diminimalisir.

02

Automation Approach

Scoring Flow Testing

Mengotomatiskan alur scoring juri — dari input poin sampai perhitungan hasil akhir, memastikan akurasi data di setiap tahap.

Match Schedule Verification

Test otomatis untuk memverifikasi urutan pertandingan, pengelompokan peserta, dan status jadwal yang tampil real-time.

Real-time Sync Check

Memastikan data yang ditampilkan ke panel juri, meja, dan penonton selalu sinkron lewat pengujian state & re-render.

Regression Protection

Menjaga fitur yang sudah berjalan tidak rusak saat ada penambahan fitur baru lewat automated regression testing.

03

Automation Workflow

01

Test Analysis

Mengidentifikasi alur kritis yang paling berisiko dan berdampak besar jika terjadi bug saat pertandingan.

02

Script Writing

Menulis test script otomasi untuk alur scoring, jadwal, dan sinkronisasi data dengan framework yang stabil.

03

Execution & Debug

Menjalankan test suite, menganalisis kegagalan, dan memperbaiki flaky test agar hasilnya konsisten.

04

Maintenance

Terus memperbarui test suite mengikuti perubahan fitur dan kebutuhan turnamen.
