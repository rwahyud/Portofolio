# Rizki Tri Wahyudi — Portfolio

Personal portfolio website showcasing projects and skills as a Developer, QA Engineer, and Project Manager.

**Live:** [portofolio.pages.dev](https://portofolio.pages.dev)

## Features

- Bilingual support (ID/EN)
- 3D project carousel with touch swipe
- Custom cursor + animations
- Responsive design (mobile, tablet, desktop)
- Animated skill bars + reveal on scroll
- Canvas wireframe background
- Visitor counter

## Tech Stack

- HTML5 / CSS3 / JavaScript (Vanilla)
- Firebase Hosting
- Cloudflare Pages
- Figma (Design)

## Run Locally

```bash
# Clone
git clone https://github.com/rwahyud/Portofolio.git
cd Portofolio

# Open in browser
start index.html
```
